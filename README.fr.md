# Julien Esterbet

Développeur logiciel orienté applications full-stack, FinTech et Web3.

Je conçois des logiciels avec une approche produit : comprendre le besoin
métier, définir une architecture maintenable, tester les parcours importants,
documenter le système et livrer une solution réellement utilisable.

Mon travail actuel se concentre sur les applications TypeScript, les logiciels
local-first et les produits liés à la finance ou à la blockchain. Je conserve
également ici certains projets académiques et d'apprentissage lorsqu'ils
illustrent un concept technique utile.

## Projets principaux

### [Bruno Pizza — Production](https://github.com/JulienEsbt/bruno-pizza-production)

Une application desktop local-first conçue pour un contexte métier réel. Elle
importe et valide des plans de production Excel, gère un catalogue produit dans
SQLite et guide les opérateurs à travers les recettes et les étapes de
fabrication.

Le projet utilise React, TypeScript, Electron, Express et SQLite. L'application
est testée, documentée, packagée et distribuée pour Windows et macOS.

### [Site personnel et portfolio](https://github.com/JulienEsbt/My-Website)

Mon portfolio React multilingue, déployé sur Vercel. Il réunit mes projets
logiciels, des cartes de voyage, des réflexions longues au format MDX et des
expérimentations Web3 dans une même application.

[Voir le site](https://www.julien-esterbet.com)
