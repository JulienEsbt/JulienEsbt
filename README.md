# Julien Esterbet

Software developer and IT analyst working on full-stack applications, business software and financial systems.

I build reliable and maintainable software with a product mindset: understanding the operational context, designing a clear architecture, testing the important paths, documenting decisions and delivering tools people can actually use.

My current work includes TypeScript applications, local-first software, financial systems and selected blockchain projects. I also keep academic and learning projects here when they demonstrate a useful technical concept.

My professional background is technical and financial, but my interests extend far beyond technology. I am especially interested in philosophy, psychology, sociology, geopolitics, democracy, sovereignty and public debate. I value in-depth discussion, the honest examination of opposing ideas and understanding where disagreements actually lie.

Technology is therefore both a professional field and an object of critical reflection for me—not the centre of every question, nor an automatic answer to human and social problems.

## Featured projects

### [Bruno Pizza — Production](https://github.com/JulienEsbt/bruno-pizza-production)

A local-first desktop production tool built for a real operational context. It imports and validates Excel production plans, manages a SQLite-backed product catalogue and guides operators through recipes and production steps.

Built with React, TypeScript, Electron, Express and SQLite. The application is tested, documented, packaged and distributed for Windows and macOS.

### [Personal website and portfolio](https://github.com/JulienEsbt/My-Website)

My multilingual React portfolio, deployed on Vercel. It brings together my software projects, travel maps, long-form reflections, MDX content and Web3 experiments in one application.
