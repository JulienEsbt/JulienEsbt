# Julien Esterbet

Software developer focused on full-stack applications, FinTech and Web3.

I build software with a product mindset: understanding the operational need,
designing a maintainable architecture, testing the important paths, documenting
the system and delivering something people can actually use.

My current work is centered on TypeScript applications, local-first software and
financial or blockchain-related products. I also keep selected academic and
learning projects here when they demonstrate a useful technical concept.

## Featured projects

### [Bruno Pizza — Production](https://github.com/JulienEsbt/bruno-pizza-production)

A local-first desktop production tool built for a real operational context. It
imports and validates Excel production plans, manages a SQLite-backed product
catalog and guides operators through recipes and production steps.

Built with React, TypeScript, Electron, Express and SQLite. The application is
tested, documented, packaged and distributed for Windows and macOS.

### [Personal website and portfolio](https://github.com/JulienEsbt/My-Website)

My multilingual React portfolio, deployed on Vercel. It brings together my
software projects, travel maps, long-form reflections, MDX content and Web3
experiments in one application.

[Visit the website](https://www.julien-esterbet.com)
